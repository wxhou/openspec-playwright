快速开始Quick Start

5 分钟上手Get Started in 5 Minutes

安装后跑一次 init，剩下的交给命令：init 自动检测编辑器并按各自规范装好命令工件；Claude Code 里用 /opsx:e2e，OpenCode / Cline / Cursor / Pi / Oh My Pi 用 /opsx-e2e。 Install, run init once, and let the command take over: init auto-detects your editors and installs the command artifacts in each editor's convention. Use /opsx:e2e in Claude Code, /opsx-e2e in OpenCode, Cline, Cursor, Pi, and Oh My Pi.

terminal
$ npm install -g @fission-ai/openspec@latest
$ openspec init
$ npm install -g openspec-playwright@latest
$ openspec-pw init
$ npx playwright install chromium
# In Claude Code:
$ /opsx:e2e <change-name>
